# Code review 006 — ST-009 (internal/agent)

## Итерация 1 — valid=false, три находки

**HIGH, гонка в тесте VC2.** Monitor проверил мутацией: с убранным обработчиком Update тест падал только на втором assert. Первый — добавление аннотации живому поду — проходил случайно из-за гонки между синхронным `client.Update()` в тесте и асинхронным начальным `List()` информера. Doc-комментарий теста при этом утверждал, что Add-only реализация «fails both assertions».

**MEDIUM, дублирование `toCgroupQoSClass`** в `internal/apply/apply.go` и `internal/agent/reconciler.go`. Разойдутся копии — реконсайлер проверяет сходимость по одному пути, применитель пишет в другой, молча. В `apply.go` при этом стоял комментарий «the one place the mapping happens».

**LOW, устаревший `informers.NewFilteredSharedInformerFactory`.** Старую форму подсказала я в постановке.

## Итерация 2 — закрыто

Гонка убрана: тест синхронно ждёт `WaitForCacheSync` до первого `Update`. Мутация с удалённым `UpdateFunc` теперь валит тест детерминированно, 3 прогона из 3.

Actor честно разобрал требование «падать на обоих assert'ах»: `t.Fatalf` прерывает подтест на первом же провале, поэтому два падения в одном прогоне структурно невозможны. Отдельной проверкой через `t.Errorf` он показал, что второй и третий assert под мутантом проходят тривиально — начальное состояние фикстуры совпадает и с «тира не запрошено», и с целью снятия. Ложное утверждение в комментарии заменено описанием реального режима отказа. Формулировка критерия в контракте была неточной, а не реализация.

Отображение вынесено в `qos.ToCgroupClass`. Actor нашёл **третье** место вызова в `revert.go`, которое не заметили ни я, ни Monitor.

Информер переведён на `NewSharedInformerFactoryWithOptions`; тест VC4 на fieldSelector остался зелёным и как раз стерёг эту миграцию.

## Хвост

Resync-путь не покрыт тестом через настоящий informer с коротким периодом: VC1 и VC2 используют час, VC3 передаёт флаг в `Reconcile` напрямую. Логика различения по `ResourceVersion` корректна при чтении, но живым прогоном не проверена. Вне критериев ST-009.
