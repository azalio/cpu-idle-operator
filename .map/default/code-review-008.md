# Code review 008 — ST-012 (манифесты)

## Ложная находка ревьюера — снята

Я заявила, что `hack/check-manifests.sh` не ловит лишний глагол `delete` в ClusterRole, и вернула подзадачу на доработку. **Это была моя ошибка.**

Причина: в `config/base/rbac.yaml` глаголы записаны в flow-стиле — `verbs: ["get", "list", "watch"]`. Моя инъекция искала блочный список (`      - watch`) и не нашла его. `str.replace` без совпадения молча вернул исходную строку, я не проверила результат подстановки, и скрипт честно отработал на **нетронутом** файле, напечатав `all checks passed`.

То есть я совершила ровно ту ошибку, которую в этом прогоне ловила у других трижды: заявила результат проверки, не убедившись, что проверка вообще что-то проверяла. Actor оспорил находку, привёл md5 файла и попросил перепроверить — и был прав.

## Перепроверка с подтверждённым diff

| Инъекция | Результат |
|---|---|
| `verbs: [..., "delete"]` на pods | `FAIL: VC2: pods rule verbs are not exactly [get,list,watch]` |
| `resources: ["pods", "nodes"]` | `FAIL: VC2: ClusterRole grants an unexpected rule beyond pods/events` |
| `privileged: true` в DaemonSet | `FAIL: VC1: rendered manifest sets privileged: true` |

Проверка RBAC построена на точном сравнении множеств через `yq`, а не на поиске подстрок: сортированное JSON-сравнение глаголов и apiGroups, отдельная проверка количества правил и отдельная — на «лишние» правила. VC2 выполнен.

Третья моя инъекция (дописать новое правило в конец файла) сломала YAML и уронила `kustomize` — дефект инъекции, не скрипта. Actor проверил корректный вариант этого случая: `FAIL: VC2: ClusterRole has 3 rule(s), expected exactly 2`.
